# Python Dictionary Practice

A small Python project created to practise using dictionaries and working with key-value pairs.

## Features
- Creates dictionaries to store student information.
- Accesses values using dictionary keys.
- Updates existing dictionary values.
- Adds new key-value pairs.
- Stores and modifies lists inside dictionaries.
- Displays dictionary information.

## Concepts Practised
- Python dictionaries
- Key-value pairs
- Lists inside dictionaries
- Accessing and modifying data
- Adding new dictionary entries
- Boolean values

## Technologies
- Python 3

## How to Run
1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command in the terminal:

```bash
python python_dictionary_practice.py
```

## Purpose
This project was created as part of my journey towards developing stronger Python programming skills, particularly with data structures and information management.
